AI PDF Analyser

Модуль для анализа документов формата PDF, который отвечает на заданный вопрос, используя только информацию из отправленного файла. В основе заложена архитектура RAG, позволяющая подбирает наиболее похожую информацию из документа, если таковая имеется.

Созданы 2 версии: консольная и для Telegram-бота. Инструкции по установке и использованию написаны в GitHub репозитории проекта.

Стэк разработки: Python 3.13

Ссылка на GitHub: https://github.com/Veidge/AI_FileModule.git
