# WebVeidge

Сайт пользователя Veidge, созданный с целью собрать основную и актуальную информацию, разместив её в удобном формате.

## О сайте

Создан изначально на стеке HTML + CSS. В последствии переведён на Vue.
Отображает основную информацию, что может понадобиться при запросе или отклике.
Содержит навыки, проекты с ссылками на них, контакты. 
Дополнительно сделана полная адаптация. 

## Установка проекта

1. Перенести репозиторий в проект:

```console
git clone https://github.com/Veidge/Business_card_Veidge
cd Business_card_Veidge
```

2. В установленном проекте загрузите `node_modules`, необходимые для запуска: 

```sh
npm install
```

3. Запустите проект:

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
