AI Module for file and docs analyze

Модуль для анализа документов и текстовых файлов, который отвечает на заданный вопрос используя только информацию из отправленного файла или документа. В основе заложена архитектура RAG.

Завершённые проекты

Мобильное приложение "Фильмы"

Приложение на Android с системой авторизации для записи на сеанс фильма с базой данных. В приложении представлен список фильмов, на которые можно записаться (таблица с постерами фильмов и всеми необходимыми данными). При клике на фильм система уведомит вас о записи. Дополнительно в приложении задан аккаунт админа, который позволяет добавлять фильмы в базу данных.

Стэк разработки: Java, (Android Studio), SQLite

Сайт "Цифровой старт"

Сайт совместного проекта, посвящённому мероприятиям в сфере IT, организаций ООО "Асандра" и ООО "Логасофт ПЛЮС". Любой желающий может записаться, отправив заявку, размещённую на сайте, до начала самого мероприятия. На сайте присутствует интерактивная Яндекс Карта, с помощью которой можно легко понять, как добраться до места проведения мероприятия. Для корректного понимания времени на сайте создан таймер, который показывает оставшееся время приёма заявок до заданной даты.

Стэк разработки: HTML, CSS, JavaScript

Шифратор "Cryptonit"

Десктопное приложение-шифратор, который позволяет шифровать текст и текстовые файлы различными способами. Доступен выбор шифрования или дешифрования, по нажатию клавишы F1 открывается справка. Для удобства использования есть функция переключения тем (светлая / тёмная). Удобно копировать и вставлять текст при помощи базовых комбинаций клавиш или с помощью специальных виджетов интерфейса.

Стэк разработки: Python 3.13

Prime Parser

Десктопное приложение для автоматизации отслеживания динамики цен на платформе warframe.market. Реализован поиск по API и добавление наиболее выгодного предложения в таблицу приложения в режиме реального времени. По каждому товару есть графики динамики цены.

Исходный репозиторий работы с PrimeParser: https://github.com/Tenebrea/warframe-market-parser.git

Стэк разработки: Python 3.13, QT Designer

Weather Parser

Мобильное приложение для получения данных о погоде в выбранном городе. Все данные приходят по API с достоверного источника. Города можно просмотреть или сохранить в избранное для удобного и быстрого отслеживания.

Стэк разработки: Kotlin

Achievement Tracker

Десктопное приложение для фиксации данных о своих успехах / достижениях / заметках с удобным хранением. Предусмотрено создание отдельных баз данных и таблиц, удаление и изменение данных. Для числовых значений можно построить график для наглядности динамики результатов.

Стэк разработки: Python 3.13, SQLite

Игра Spaceship

Десктопная игра про управление кораблём и выживание под обстрелом вражеских кораблей. Реализована система управления и ведения огня, регистрация попаданий по врагу. За каждую игру накапливаются очки, которые фиксируются и показываются как рекорд.

Стэк разработки: Python 3.13
