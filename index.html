Приложение "КиноВитрина"

Приложение на Android с системой авторизации для записи на сеанс фильма с базой данных. В приложении представлен список фильмов, на которые можно записаться (таблица с постерами фильмов и всеми необходимыми данными). При клике на фильм система уведомит вас о записи. Дополнительно в приложении задан аккаунт админа, который позволяет добавлять фильмы в базу данных.

Сайт "Цифровой старт"

Шифратор "Cryptonit"

Десктопное приложение-шифратор, который позволяет шифровать текст и текстовые файлы различными способами. Доступен выбор шифрования или дешифрования, по нажатию клавишы F1 открывается справка. Для удобства использования есть функция переключения тем (светлая / тёмная). Удобно копировать и вставлять текст при помощи базовых комбинаций клавиш или с помощью специальных виджетов интерфейса.

Стэк разработки: Python 3.13
