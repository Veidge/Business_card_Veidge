<p class="p_proj">
Мобильное приложение для получения данных о погоде в выбранном городе. 
Все данные приходят по API с достоверного источника. 
Города можно просмотреть или сохранить в избранное для удобного и быстрого отслеживания.
</p>
<p>Стэк разработки: Python 3.13, QT Designer</p>
