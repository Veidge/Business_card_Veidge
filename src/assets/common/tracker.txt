<p>
Десктопное приложение для фиксации данных о своих успехах / достижениях / заметках с удобным хранением. Предусмотрено создание отдельных баз данных и таблиц, удаление и изменение данных. Для числовых значений можно построить график для наглядности динамики результатов.
</p>
<p>
Стэк разработки: Python 3.13, SQLite
</p>
